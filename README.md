# Bappa’s Modak Quest

A Ganesh Chaturthi-themed 2D platform adventure built with HTML, CSS, and JavaScript.

## Play
Open index.html in a modern browser. No build or installation is required.

Use arrow keys or A/D to move, Space to jump and double jump, and P to pause. Mobile players can use the onscreen controls.

Collect at least 15 modaks and all 5 flowers, solve the lamp puzzle (pink, yellow, lotus), and reach the pandal. Losing three hearts ends the game.

## Files
- index.html: interface
- style.css: responsive styling
- game.js: game rules, controls, and canvas rendering
- festival-village.png: AI-generated festival artwork
- favicon.svg: game icon

Created with assistance from ChatGPT/Codex. Emoji appearance varies by device.
